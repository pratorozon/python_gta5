## 🎯 Что это такое

**BP-очки** — настольное приложение на Python (Tkinter) для удобного отслеживания ежедневных заданий, за которые начисляются бонусные очки (BP).

Возможности:

- ✅ Список всех заданий, сгруппированных по разделам
- ⭐ Добавление заданий в «Избранное» (звёздочка)
- ➕ Учёт прогресса для многошаговых заданий (−1 / ввод / +1)
- ⏱ Таймеры с обратным отсчётом и звуковым сигналом
- 💰 Автоматический подсчёт полученных BP (с учётом множителей)
- 🔍 Поиск и фильтрация
- 💾 Автосохранение в JSON
- 📝 Логирование ошибок в отдельный файл

## 💻 Требования и установка

### Требования

| Параметр | Значение |
|----------|----------|
| ОС | Windows (звук работает через `winsound`) |
| Python | 3.8 и новее |
| Доп. библиотеки | **не требуются** (используется только стандартная библиотека) |

### Установка

1. Установите Python с [python.org](https://www.python.org/downloads/). При установке отметьте галочку **«Add Python to PATH»**.
2. Поместите файл `bp.py` в любую удобную папку (например, `C:\BP_Tracker\`).
3. Никаких дополнительных пакетов ставить не нужно.

> ⚠️ Если при двойном клике по `.py` ничего не происходит — возможно, у вас не настроена ассоциация файлов. Запускайте через `python bp.py` (см. ниже).

## 🚀 Запуск

### Способ 1 — через проводник

Двойной клик по файлу `bp.py`.

### Способ 2 — через командную строку

```cmd
cd путь\к\папке
python bp.py
```

### Способ 3 — создать ярлык `.bat`

Создайте рядом файл `Запуск.bat` с содержимым:

```bat
@echo off
python "%~dp0bp.py"
pause
```

И запускайте через него — так вы увидите ошибку при старте, если что-то не так.

- **Панель вкладок** — переключение между разделами.
- **Сетка карточек** — сами задания (3 колонки).

## 📋 Работа с заданиями

Каждая карточка содержит:

| Элемент | Описание |
|---------|----------|
| **Раздел** (сверху) | К какой группе относится задание |
| **★** | Добавить/убрать из Избранного |
| **Заголовок** | Полное название задания (синий) |
| **Подзаголовок** | Короткое название в скобках |
| **Бейдж BP** | Сколько BP даёт (с учётом множителей) |
| **Статус** | «✓ выполнено» (зелёный) |
| **Полоса прогресса** | Показывает выполнение |
| **Счётчик** | `Прогресс: X / Y` |
| **Кнопки управления** | `−1` / поле ввода / `+1` или `Выполнить` |
| **⏱ Таймер** | Если у задания есть время |

### Как отметить задание выполненным

**Для разовых заданий** (без счётчика):

1. Нажмите кнопку **«Выполнить»** — задание сразу засчитывается.

**Для многошаговых заданий** (со счётчиком):

1. Жмите **+1** после каждого действия.
2. Или введите нужное число в поле вручную и нажмите **Enter** (или кликните вне поля).
3. Когда прогресс достигнет нужного числа — задание автоматически станет «выполнено».

> 💡 Ошиблись? Нажмите **−1** или введите меньшее число — можно корректировать прогресс в любую сторону, пока задание не выполнено.

### Как убрать из выполненных

Если задание помечено выполненным, но вы отметили его по ошибке:

- Для **разовых** — кнопка заблокирована. Сбросьте день (см. [Кнопки верхней панели](#-кнопки-верхней-панели)).
- Для **многошаговых** — уменьшить прогресс нельзя, пока не начнётся новый день.

> ⚠️ Будьте внимательны при вводе большого числа — после достижения лимита прогресс фиксируется.

## 🔢 Разовые задания и задания с прогрессом

### Разовые

У задания `limit = None`. Показывается кнопка **«Выполнить»**.  
Пример: *«Купить лотерейный билет»*, *«Арендовать киностудию»*.

### С прогрессом

У задания `limit = число` (например, 5, 10, 25). Показываются кнопки **−1 / поле ввода / +1**.  
Пример: *«Добавить 5 видео в кинотеатре»* (limit=5), *«25 действий на стройке»* (limit=25).

> 🎯 Прогресс не может превысить лимит — система сама зафиксирует выполнение.

## ⏱ Таймеры

У некоторых заданий есть таймер (например, *«Поиграть 1 минуту в настольный теннис»*).

### Как пользоваться

1. Найдите кнопку **⏱ N мин** (справа в карточке).
2. Нажмите — запустится обратный отсчёт (формат `MM:SS`).
3. По окончании прозвучит **звуковой сигнал** (два «бипа»).
4. Надпись сменится на **«⏱ время вышло»** (красным).

### Особенности

- Отсчёт идёт даже если вы переключились на другую вкладку.
- Если **свернуть** окно — таймер продолжает работать.
- Повторно запустить таймер можно после завершения (кнопка снова активна).
- ❗ Таймер **не привязан** к выполнению задания: вы можете отдельно нажать «Выполнить» и отдельно запустить таймер.

## 💰 Множители BP (VIP / x2)

В верхней панели два чекбокса:

| Чекбокс | Эффект |
|---------|--------|
| **VIP ×2** | Умножает BP на 2 |
| **x2 ×2** | Умножает BP на 2 |

- Оба включены → **×4**.
- Множители применяются к:
  - Бейджу **+N BP** на карточке
  - Счётчику **★ N BP** (избранное)
  - Счётчику **Всего: N BP**

> 💡 Счётчики считают **только выполненные** задания. Прогресс незавершённых в сумму не входит.

## 🔍 Поиск и фильтр «Скрыть готовое»

### Поиск

- Поле **«Поиск»** в верхней панели.
- Ищет по **полному** и **короткому** названию.
- Работает **внутри активной вкладки**.
- Регистр не важен.
- Пример: введите `ферма` — останутся только задания со словом «ферма».

### «Скрыть готовое»

Кнопка-переключатель:

- **Скрыть готовое** — задания с отметкой «выполнено» исчезают из списка.
- Повторное нажатие → **Показать готовое** (кнопка становится оранжевой).
- Состояние сохраняется между запусками.

> 💡 Удобно, когда нужно видеть только то, что осталось сделать.

## 🎛 Кнопки верхней панели

| Кнопка | Действие |
|--------|----------|
| **Новый день** | Сбрасывает **прогресс и отметки «выполнено»** у всех заданий. Избранное и множители сохраняются. Спрашивает подтверждение. |
| **Сброс БП** | То же, что «Новый день», но кнопка красная — для явного сброса. Спрашивает подтверждение. |
| **Сохранить** | Принудительно записывает данные в файл и показывает путь к нему. |

> ℹ️ «Новый день» и «Сброс БП» делают одно и то же — различие только в цвете кнопки для удобства (зелёная/красная).

## 💾 Сохранение данных

### Автосохранение

Данные сохраняются **автоматически** при:

- Изменении прогресса
- Отметке «выполнено»
- Изменении избранного
- Переключении множителей
- Переключении «Скрыть готовое»
- Нажатии «Новый день» / «Сброс БП»
- Закрытии окна

### Где хранится файл

Приложение пытается сохранить данные в первый доступный каталог:

1. Папка с `bp.py`
2. `%APPDATA%\BP_Tracker\`
3. `~/.bp_tracker/`
4. Временная папка (`temp`)

Файлы:

- **`bp_config.json`** — все настройки и прогресс
- **`error.log`** — лог ошибок (если что-то пошло не так)

> 📌 Точный путь можно увидеть, нажав кнопку **«Сохранить»** — появится окно с путём.

### Резервная копия

Скопируйте `bp_config.json` в надёжное место. Для восстановления — верните файл обратно.

### Сброс всех данных

Удалите `bp_config.json` — при следующем запуске настройки будут по умолчанию (все задания не выполнены, избранное пустое).

## 🛠 Возможные проблемы и решения

### Приложение не запускается / чёрное окно с ошибкой

1. Откройте `error.log` (путь указан в окне ошибки).
2. Проверьте, что установлен Python 3.8+.
3. Попробуйте запустить через `Запуск.bat` — увидите текст ошибки.

### Данные не сохраняются

- Проверьте права на запись в папку с `bp.py`.
- Если папка защищена — приложение автоматически уйдёт в `%APPDATA%\BP_Tracker\`.
- Нажмите «Сохранить» и посмотрите путь в окне.

### Нет звука таймера

- Звук работает через `winsound` (только Windows).
- Проверьте системный звук и микшер.
- На Linux/macOS будет использован системный «бип» окна.

### Таймер «завис» после сворачивания

- Это нормально: отсчёт идёт в фоновом потоке.
- Значение обновляется раз в 0.5 сек.
- Разверните окно — увидите актуальное время.

### Сбросились все задания после перезапуска

- Файл `bp_config.json` не найден или перезаписан.
- Проверьте путь (кнопка «Сохранить»).
- Восстановите из резервной копии.

### Окно слишком маленькое / не помещается

- Минимальный размер — `1000×600`.
- Разверните окно на весь экран (двойной клик по заголовку).

### Карточки «наезжают» друг на друга

- Увеличьте ширину окна (сетка на 3 колонки, минимум ~1080 px по ширине).

```json
    }
  }

```

## ✅ Краткая шпаргалка «первый запуск»

1. Запустить `bp.py`.
2. Отметить ⭐ нужные задания.
3. Перейти во вкладку **«Избранное»**.
4. Выполнять задания: **«Выполнить»** или **+1 / −1**.
5. Следить за счётчиком **Всего: N BP** вверху.
6. В конце дня нажать **«Новый день»**.
7. Данные сохранятся автоматически.

## 🎯 Что это такое

**Skills** — настольное приложение на Python (Tkinter) для отслеживания текущего уровня и накопленного опыта по каждой профессии.

Возможности:

- ✅ Все профессии в одном окне, сгруппированы в сетку
- 📊 Наглядный прогресс до следующего уровня
- 🔢 Учёт опыта с автоматическим повышением уровня
- ➕ Кнопки быстрого добавления опыта (−1 / +1)
- 🏆 Кнопка **MAX** — мгновенно прокачать профессию до максимума
- 💰 Учёт множителей опыта (VIP ×2, x2 ×2)
- 🔤 Регулировка размера шрифта
- ❓ Справка по каждой профессии (что даёт каждый уровень)
- 💾 Автосохранение в JSON

## 💻 Требования и установка

### Требования

| Параметр | Значение |
|----------|----------|
| ОС | Windows (используется `ctypes` для перезапуска от админа) |
| Python | 3.8 и новее |
| Доп. библиотеки | **не требуются** (только стандартная библиотека) |

### Установка

1. Установите Python с [python.org](https://www.python.org/downloads/). При установке отметьте **«Add Python to PATH»**.
2. Поместите файл `skills.py` в любую удобную папку (например, `C:\Skills_Tracker\`).
3. Дополнительных пакетов ставить не нужно.

> ⚠️ Если при двойном клике по `.py` ничего не происходит — запускайте через `python skills.py`.

## 🚀 Запуск

### Способ 1 — через проводник

Двойной клик по `skills.py`.

### Способ 2 — через командную строку

```cmd
cd путь\к\папке
python skills.py
```

### Способ 3 — ярлык `.bat`

Создайте рядом `Запуск.bat`:

```bat
@echo off
python "%~dp0skills.py"
pause
```

> 💡 Если данные не сохраняются из-за прав на папку — приложение предложит перезапуск от имени администратора.


**Основные элементы:**

- **Верхняя панель** — заголовок, регулятор шрифта, множители, кнопки.
- **Сетка карточек** — все профессии (3 колонки).
- **Прокрутка** — колесо мыши или полоса справа.

## 🗂 Карточка навыка

Каждая карточка содержит:

| Элемент | Описание |
|---------|----------|
| **Кружок с буквой** | Первая буква названия профессии |
| **Бейдж уровня** | Текущий уровень (0–5) |
| **Название** | Профессия |
| **?** | Справка по профессии |
| **Выпадающий список** | Выбор текущего уровня (0…макс) |
| **Опыт** | Поле ввода текущего опыта |
| **− / +** | Быстрое изменение опыта на множитель |
| **MAX** | Мгновенно поставить максимальный уровень |
| **Статус** | `ещё N (д: M)` или `Максимальный уровень` |

> 💡 Цвет кружка: **оранжевый** — в процессе, **зелёный** — максимальный уровень.

## 🔼 Изменение уровня

### Через выпадающий список

1. Нажмите на поле с текущим уровнем (`[0▾]`).
2. Выберите нужный уровень от 0 до максимума (обычно 5).
3. Опыт **сбрасывается в 0**, уровень применяется.

> ⚠️ Ручное изменение уровня **обнуляет накопленный опыт** текущего уровня.

### Автоматическое повышение

Уровень повышается **сам**, когда опыт достигает требования:

- Например, у «Рыбака» с 0 на 1 нужно **25** опыта.
- Набрали 25 → уровень стал **1**, опыт обнулился до 0 (излишек переносится).

> 🎯 Система сама «съедает» нужное количество опыта и повышает уровень, пока хватает накопленного.

## 🧮 Работа с опытом

### Ввод вручную

1. Кликните в поле **«Опыт»**.
2. Введите число.
3. Нажмите **Enter** или кликните вне поля — прогресс применится.

### Кнопки − / +

- **+** прибавляет к опыту **текущий множитель** (1 / 2 / 4).
- **−** отнимает столько же (но не ниже 0).
- Удобно для быстрого учёта действий.

> 💡 Если ввели слишком много — можно ввести меньше вручную (пока уровень не перескочил). После повышения уровня лишнее сгорает.

### Индикатор «ещё N (д: M)»

- **N** — сколько опыта осталось до следующего уровня.
- **M (д: …)** — сколько **действий** нужно сделать с учётом множителя.
  - Пример: осталось 100 опыта, множитель ×4 → «д: 25» (25 действий по 4 опыта).

> ✅ Когда профессия прокачана до максимума — вместо этого пишется **«Максимальный уровень»** (зелёным).

---

## 🏆 Кнопка MAX

- Мгновенно ставит **максимальный уровень** профессии.
- Опыт сбрасывается в 0.
- Кнопка становится **неактивной** после нажатия (пока не сбросите уровень).

> ⚠️ Используйте с осторожностью — обратно вернуть промежуточный прогресс нельзя, только сбросить до нужного уровня вручную.

---

## 💰 Множители опыта (VIP / x2)

В верхней панели два чекбокса:

| Чекбокс | Эффект |
|---------|--------|
| **VIP (×2)** | Умножает прибавку опыта на 2 |
| **x2 (×2)** | Умножает прибавку опыта на 2 |

- Оба включены → **×4**.
- Множитель влияет на:
  - Кнопки **+ / −** (шаг изменения)
  - Расчёт **«д: M»** в статусе
- Ручной ввод в поле опыт **не** умножается.

> 💡 Пример: осталось 100 опыта, ×4 → статус покажет «ещё 100 (д: 25)». Нажатие **+** добавит сразу 4.

---

## 🔤 Масштаб шрифта

Слайдер **«Шрифт»** в верхней панели:

- Диапазон: **7–16**.
- Меняет размер текста во всех карточках.
- Значение **сохраняется** между запусками.

> 💡 Удобно для мониторов с высоким разрешением или для чтения без напряжения.

---

## ❓ Кнопка «?» и справка

Кнопка **?** справа в карточке открывает окно с:

- **Описанием** профессии (что даёт каждый уровень).
- **Требованиями** по опыту для каждого перехода.

Пример для «Рыбак»:

```
Профессия. 3, 4, 5, 6 уровни открывают больше рыбы.

Требования:
  с 0 на 1: 25 опыта
  с 1 на 2: 75 опыта
  ...
```

## 🎛 Кнопки верхней панели

| Кнопка | Действие |
|--------|----------|
| **Сохранить** | Принудительно записывает данные и показывает путь к файлу. При ошибке доступа предлагает перезапуск от администратора. |
| **Сбросить ВСЁ** | Удаляет файл конфигурации и **перезапускает приложение**. Спрашивает подтверждение. |

> ℹ️ «Сбросить ВСЁ» — это полный сброс всех профессий, множителей и настроек шрифта.

## 💾 Сохранение данных

### Автосохранение

Данные сохраняются **автоматически** при:

- Изменении уровня
- Вводе опыта
- Нажатии − / +
- Нажатии MAX
- Переключении множителей
- Изменении шрифта
- Закрытии окна

### Где хранится файл

Файл **`skills_config.json`** лежит **рядом со скриптом** `skills.py` (в той же папке).

> 📌 Точный путь можно увидеть, нажав кнопку **«Сохранить»**.

### Структура `skills_config.json`

```json
{
  "__globals__": {
    "vip": false,
    "x2": false,
    "font_size": 9
  },
  "Рыбак": {
    "level": 1,
    "current": 10
  },
  "Охотник": {
    "level": 0,
    "current": 0
  }
}
```

### Резервная копия

Скопируйте `skills_config.json` в надёжное место. Для восстановления — верните файл обратно и перезапустите приложение.

### Сброс всех данных

- Нажмите **«Сбросить ВСЁ»** (с подтверждением) — приложение перезапустится с чистыми данными.
- Или удалите `skills_config.json` вручную.

## 🛠 Возможные проблемы и решения

### Данные не сохраняются

- Проверьте права на запись в папку со скриптом.
- При нажатии **«Сохранить»** приложение предложит **перезапуск от администратора**.
- Как альтернатива — перенесите папку в `C:\Users\ВашеИмя\Documents\`.

### Профессия не повышается при вводе опыта

- Убедитесь, что введённое число **≥ требования** следующего уровня.
- Проверьте, что не выбран **максимальный** уровень — тогда опыт заблокирован.
- Уровень повышается **только** при нажатии **Enter** или уходе из поля.

### Опыт «сгорает» после повышения уровня

- Это нормальное поведение: излишек переносится на следующий уровень. Если его не хватает — обнуляется.
- Пример: нужно 25, ввели 30 → уровень +1, опыт стал 5.

### Уровень установился, а опыт остался прежним

- Ручное изменение уровня через выпадающий список **сбрасывает опыт в 0**.
- Если опыт был нужен — введите его заново.

### Кнопка MAX не работает

- Проверьте, что профессия **не прокачана** до максимума — тогда кнопка неактивна.
- Если вы уже нажали MAX — вернитесь на нужный уровень через выпадающий список.

### Окно слишком маленькое

- Минимальный размер — `1300×500`.
- Разверните окно на весь экран.
- Уменьшите размер шрифта слайдером, если текст не помещается.

### Приложение «зависает» при старте

- Возможно, повреждён `skills_config.json`. Удалите его — приложение запустится с чистыми данными.
- Или проверьте лог в консоли (запуск через `Запуск.bat` покажет ошибку).

## ✅ Краткая шпаргалка «первый запуск»

1. Запустить `skills.py`.
2. Выбрать нужный уровень в выпадающем списке (или оставить 0).
3. Ввести накопленный опыт в поле **«Опыт»** и нажать **Enter**.
4. Следить за подсказкой **«ещё N (д: M)»**.
5. Использовать **− / +** для быстрого добавления (с учётом множителей).
6. При необходимости нажать **MAX** для мгновенной прокачки.
7. Данные сохранятся автоматически.

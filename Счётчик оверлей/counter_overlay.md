## 🎯 Что это такое

**Counter Overlay** — маленькое полупрозрачное окно-счётчик, которое висит **поверх всех окон** и считает:

- нажатия выбранной **клавиши** на клавиатуре;
- клики выбранной **кнопки мыши**.

Приложение полезно, когда нужно быстро считать однотипные действия в игре или программе (например, «сколько раз я нажал ЛКМ», «сколько раз нажал пробел»), не переключаясь из окна игры.

Возможности:

- ✅ Счётчик кликов/нажатий **поверх всех окон**
- 🎯 Назначение любой клавиши или кнопки мыши
- 🔄 Режим подсчёта после назначения
- ➕➖ Ручная правка счёта (−1 / +1)
- 🎚 Регулировка прозрачности (α)
- 🖱 Перетаскивание окна за верхнюю панель
- 🔴 Сброс и выход

## 💻 Требования и установка

### Требования

| Параметр | Значение |
|----------|----------|
| ОС | Windows / Linux / macOS (Tkinter + pynput) |
| Python | 3.8 и новее |
| Доп. библиотеки | **`pynput`** |

### Установка

1. Установите Python с [python.org](https://www.python.org/downloads/). При установке отметьте **«Add Python to PATH»**.
2. Установите библиотеку `pynput`:

```cmd
pip install pynput
```

3. Поместите файл `counter_overlay.py` в любую удобную папку.

> ⚠️ На Linux/macOS `pynput` может требовать дополнительных прав (доступ к вводу). На macOS — «Универсальный доступ» в настройках безопасности.

## 🚀 Запуск

### Способ 1 — через командную строку

```cmd
cd путь\к\папке
python counter_overlay.py
```

### Способ 2 — ярлык `.bat`

Создайте рядом `Запуск.bat`:

```bat
@echo off
python "%~dp0counter_overlay.py"
pause
```

> 💡 Запуск через `.bat` удобен тем, что видно ошибки при старте (например, если `pynput` не установлен).

## 🖥 Обзор интерфейса

```
┌──────────────────────────┐
│ ▬▬▬ серая полоса ▬▬▬     │  ← за неё тащим окно
│                          │
│         0                │  ← большой счётчик (зелёный)
│                          │
│   Кнопка не назначена    │  ← инфо о назначенной клавише
│                          │
│      [ −1 ]  [ +1 ]      │  ← ручная правка
│                          │
│ [Назначить] [Сброс] [✕]  │
│                          │
│ α [———●———————]           │  ← ползунок прозрачности
└──────────────────────────┘
```

**Основные элементы:**

| Элемент | Описание |
|---------|----------|
| **Серая полоса сверху** | За неё перетаскивается окно |
| **Большая цифра** | Текущий счёт (зелёный) |
| **Текст «Кнопка: …»** | Какая клавиша/кнопка назначена |
| **−1 / +1** | Ручная корректировка счёта |
| **Назначить** | Выбрать клавишу/кнопку для подсчёта |
| **Сброс** | Обнулить счётчик |
| **✕** | Закрыть приложение |
| **α (ползунок)** | Прозрачность окна (0.15 – 1.0) |

> 🔹 По умолчанию окно **полупрозрачное** (α = 0.45), появляется в левом верхнем углу (координаты `+50+50`).

## 🎮 Как пользоваться

1. **Запустите** приложение — появится оверлей.
2. **Назначьте клавишу** — нажмите «Назначить», затем нажмите нужную клавишу или кликните мышью.
3. **Начинайте считать** — каждое нажатие/клик этой клавиши увеличивает счётчик.
4. **Тащите окно** за верхнюю серую полосу в удобное место.
5. **Регулируйте прозрачность** ползунком α.
6. Для завершения — кнопка **✕**.

> 💡 Счётчик работает **только когда окно приложения открыто**. Свернуть — нельзя (окно без рамки), можно только перетащить в угол или уменьшить прозрачность.

## 🎯 Назначение клавиши/кнопки мыши

### Как назначить

1. Нажмите кнопку **«Назначить»**.
2. Надпись сменится на **«Нажми любую кнопку...»**.
3. Нажмите нужную клавишу на клавиатуре **или** кликните мышью (ЛКМ/ПКМ/СКМ).

### Что происходит после назначения

- В строке инфо появится, например: `Кнопка: a` или `Кнопка: mouse_left`.
- Приложение **автоматически переходит в режим подсчёта**.
- Каждое нажатие этой клавиши увеличивает счёт на **+1**.

### Особенности

- **Клики по самому оверлею игнорируются** — если вы назначили ЛКМ, клики по кнопкам оверлея не считаются.
- Клавиши-модификаторы (`Shift`, `Ctrl`, `Alt`) тоже можно назначить.
- Назначить можно только **одну** клавишу/кнопку за раз; повторное назначение заменяет предыдущее.
- Для спецклавиш (например, `space`, `shift`) отображается имя без префикса `Key.` — например, `space`.

> ⚠️ Если назначить ЛКМ, то **все** клики вне оверлея будут считаться, включая клики по другим программам и игры.

---

## 🖱 Перетаскивание окна

- Тащите окно **за верхнюю серую полосу** (курсор меняется на «перемещение»).
- Внутренние элементы (счётчик, кнопки, ползунок) **не тянут** окно — только панель.
- Позиция **не сохраняется** между запусками — при старте окно снова в `+50+50`.

---

## ➕➖ Ручная правка счёта

- **−1** — уменьшить счёт на 1 (но **не ниже 0**).
- **+1** — увеличить счёт на 1.

Удобно для:

- Исправления ошибок (двойное нажатие, ложное срабатывание);
- Учёта действий, которые не были назначены.

> 💡 Минус работает «с защитой»: ниже нуля счётчик не уходит.

---

## 🎚 Прозрачность

- Ползунок **α** меняет прозрачность окна от **0.15** (почти невидимо) до **1.0** (полностью непрозрачно).
- Изменения применяются **мгновенно**.
- Значение **не сохраняется** между запусками — при следующем запуске снова 0.45.

> 💡 Поставьте α на минимум, чтобы оверлей не мешал, но был виден.

---

## 🔄 Сброс и выход

| Кнопка | Действие |
|--------|----------|
| **Сброс** | Обнуляет счётчик (счёт → 0). Назначенная клавиша **сохраняется**. |
| **✕** | Корректно завершает приложение, останавливает слушатели клавиатуры/мыши. |

> ⚠️ Если закрыть приложение «крестиком» из панели задач — слушатели могут остаться висеть. Используйте **✕** внутри оверлея.

---

## ⚠️ Важные ограничения

1. **Нет сохранения** — счётчик, назначенная клавиша и позиция окна **не сохраняются**. При каждом запуске всё с нуля.
2. **Один счётчик** — можно назначить только одну клавишу/кнопку.
3. **Только когда приложение открыто** — фонового режима нет.
4. **Игры** — некоторые игры используют **захват ввода** (DirectInput / anti-cheat), из-за чего `pynput` может не видеть нажатия. В таком случае попробуйте запустить приложение **от имени администратора**.
5. **Античиты** — использование `pynput` в онлайн-играх с античитами может быть расценено как стороннее ПО. **Используйте на свой риск.**
6. **Нет «горячей» отмены** — если назначили не ту клавишу, нажмите «Назначить» снова.

## 🛠 Возможные проблемы и решения

### Приложение не запускается — ошибка `ModuleNotFoundError: pynput`

- Установите библиотеку: `pip install pynput`.
- Если `pip` не в PATH — используйте `python -m pip install pynput`.

### Нажатия не считаются

- Проверьте, что кнопка назначена (текст «Кнопка: …» не «не назначена»).
- Убедитесь, что фокус не в поле ввода, где ввод перехватывается.
- Запустите приложение **от имени администратора** — некоторые программы и игры не отдают ввод без прав.
- На Linux/macOS проверьте разрешения на ввод (см. требования).

### Клики считаются, но не там, где нужно

- Если назначена **ЛКМ** — любые клики вне оверлея считаются, включая клики по рабочему столу. Это ожидаемо.
- Назначьте **редко используемую клавишу** (например, `F8` или `Pause`), если считаете нажатия.

### Оверлей мешает нажимать на кнопки под ним

- Уменьшите прозрачность α, но **клики всё равно проходят** — окно перехватывает их (оно поверх других).
- Перетащите окно в свободный угол.
- На Windows можно включить «сквозные клики» только через `overrideredirect` + API; в текущей версии этого нет.

### Назначение сработало на кнопку оверлея

- Клики по самому оверлею **игнорируются** при подсчёте, но **назначение** может поймать клик по оверлею. Нажимайте «Назначить» и сразу жмите нужную клавишу.

### Счётчик «убежал» вверх

- Нажмите **Сброс**.
- Или используйте **−1** для точечной правки.

### Окно пропало

- Возможно, оно за другим окном или сильно прозрачное — поставьте α выше.
- Или перезапустите приложение.

### Приложение «зависло» при закрытии

- Закрывайте через кнопку **✕**, а не через диспетчер задач.
- При зависании — завершите процесс `python.exe` в диспетчере.
